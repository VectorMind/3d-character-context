# Dragon Atlas web app

Private local Astro catalog for the external `CHARCTX_PROJECT`. Start it from
the repository root with `uv run charctx web`; the command installs pinned
dependencies when needed and reports the local URL. The server exposes only
generated previews and normalized GLBs, never source downloads.

Useful checks:

```powershell
pnpm check
pnpm build
```
